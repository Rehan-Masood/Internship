A simple Breakout-style arcade game implemented in Python.

## Overview
- Entry point: [main.py](main.py#L1)
- Dependencies listed in [requirements.txt](requirements.txt#L1)

## Requirements
- Python 3.8+ (recommended)
- Install dependencies:

```bash
pip install -r requirements.txt
```

## Run
Start the game with:

```bash
python main.py
```

## Controls
See the in-game instructions or inspect [main.py](main.py#L1) for exact controls and gameplay details.
