# Birthday Invitation Project

A simple and elegant birthday invitation webpage built with HTML and CSS.

## Project Overview
This project displays a stylish invitation card for a birthday celebration with:
- A decorative heading and subtitle
- A birthday cake image
- Event details such as date and location
- A Google Maps link for the venue

## Features
- Responsive layout
- Modern visual design
- Easy to customize with your own text and images

## How to Run
You can open the page directly in a browser:

1. Open [index.html](index.html)
2. Or serve the folder using Python:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Project Structure
- [index.html](index.html) - Main webpage structure and styling
- [cake.png](cake.png) - Birthday cake image used in the invitation

## Customization
You can edit [index.html](index.html) to change:
- The birthday message
- The date
- The location
- The button link
- The image source
