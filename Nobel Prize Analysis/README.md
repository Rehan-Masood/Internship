## Project Structure

- `main.py` - Main script to run the analysis.
- `nobel_prize_data.csv` - Dataset used by the analysis.
- `requirements.txt` - Python dependencies.

## Description

`main.py` reads the `nobel_prize_data.csv` file and performs data analysis and visualizations related to Nobel Prize winners. The script may generate summary statistics, charts, or other outputs depending on its implementation.

## Prerequisites

- Python 3.8+ installed
- Recommended: create a virtual environment

## Installation

Open a terminal and run:

```bash
python -m venv env
env\Scripts\activate
pip install -r requirements.txt
```

On non-Windows systems, activate the virtual environment with `source env/bin/activate`.

## Usage

Run the main analysis script:

```bash
python main.py
```

If `main.py` accepts command-line arguments, refer to the file header or docstring for details.

## Data

The repository includes `nobel_prize_data.csv`. Ensure this file is present in the repository root before running the script.
