# Dr. Semmelweis Analysis

This repository contains a small data analysis project exploring historical mortality data associated with Dr. Ignaz Semmelweis' work. It includes CSV datasets and a simple analysis script.

## Contents

- [annual_deaths_by_clinic.csv](annual_deaths_by_clinic.csv) — Annual deaths and admissions by clinic.
- [monthly_deaths.csv](monthly_deaths.csv) — Monthly deaths and births (or admissions) data.
- [main.py](main.py) — Primary analysis script (entry point).
- [requirements.txt](requirements.txt) — Python dependencies.

## Requirements

- Python 3.8 or newer
- Install dependencies:

```
pip install -r requirements.txt
```

## Usage

Run the analysis script:

```
python main.py
```

Depending on `main.py`, additional arguments or interactive steps may be necessary — inspect the script for details.

## Data

The CSV files are included in the repository. They are small, local datasets intended for educational analysis.
