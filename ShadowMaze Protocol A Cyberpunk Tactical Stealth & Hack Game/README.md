# ShadowMaze Protocol — Cyberpunk Tactical Stealth & Hack Game

A small experimental project implementing cyberpunk-themed tactical stealth and hacking mechanics. This repository contains a simple Python prototype named `shadowmaze_stealth.py` demonstrating core gameplay concepts.

## Features
- Turn-based tactical stealth movement
- Basic hacking/minigame mechanics
- Procedural or scripted maze encounters (prototype)

## Requirements
- Python 3.10+

## Run
1. (Optional) Create and activate a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

2. Run the prototype:

```powershell
python shadowmaze_stealth.py
```

## Controls
- Keyboard-based input (prototype). Refer to the code in `shadowmaze_stealth.py` for exact controls and prompts shown at runtime.

## Development
- The project is a single-file prototype. Extend by splitting game logic, AI, and UI into modules.
