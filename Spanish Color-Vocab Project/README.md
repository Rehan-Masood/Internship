# Color-Vocab Project

A simple static web page for teaching color vocabulary.

## Overview
This project contains a single-page web app that demonstrates color vocabulary using images and styles.

## Files
- `index.html` — main page with content and structure
- `style.css` — project styles
- `assets/images/` — image assets used in the page

## How to view
Open `index.html` in your browser by double-clicking it, or serve the folder with a simple HTTP server:

```bash
# Python 3
python -m http.server 8000
# then open http://localhost:8000
```

## Notes
- Edit `index.html` to change content or add new images in `assets/images/`.
- Styles are defined in `style.css`.
