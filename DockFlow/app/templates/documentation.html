Documentation

How to run, test, containerize and deploy DockFlow.

Quick start

python -m venv .venv
.venv\Scripts\activate   # Windows
source .venv/bin/activate  # Linux/macOS
pip install -r requirements.txt
copy .env.example .env    # Windows
cp .env.example .env      # Linux/macOS
python run.py

Docker

docker compose up --build

Health

GET /health is used by Docker and deployment platforms.

CI/CD

Push to GitHub to run tests and the Docker smoke test. Add provider-specific deployment credentials in GitHub Secrets.

Real-time rule

The dashboard does not contain screenshot-derived metrics. It polls backend APIs and displays actual state, or an explicit unavailable/not-configured state.
