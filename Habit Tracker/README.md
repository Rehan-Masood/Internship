# Habit Tracker

A small Python project to track and build habits. This repository contains a simple entry point in `main.py` — extend it with features, storage, or a UI as needed.

## Features

- Minimal CLI-driven habit tracking (starter)
- Easily extended for persistence, schedules, and analytics

## Prerequisites

- Python 3.8 or newer

## Setup

1. (Optional) Create a virtual environment:

```powershell
python -m venv venv
venv\Scripts\Activate.ps1
```

```bash
python3 -m venv venv
source venv/bin/activate
```

2. Install dependencies (if any):

```bash
pip install -r requirements.txt
```

If your project has no external dependencies yet, there is nothing to install.

## Usage

Run the application from the project root:

```bash
python main.py
```

The program will run and present its interface (CLI, GUI, or other) depending on how `main.py` is implemented. Follow on-screen prompts to add, complete, or review habits.

## Examples

- Add a habit, mark it complete, and view progress. Exact commands depend on the current implementation in `main.py`.
